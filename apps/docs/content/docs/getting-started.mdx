# Getting Started

SSF is heading toward its first release. This page tells you what you
need and what to read first. Install steps for the published CLI will
appear here with the release.

## What you need

- **Node.js LTS** (currently supported) — the only runtime requirement for
  running installed skills. No native dependencies.
- **A license key** from the skill publisher — one key covers a
  publisher's whole suite.

Publisher source code always stays private with the publisher. What you
install is the built skill package, distributed through a git repo and
installed with:

```bash
npx skills add <owner>/<repo> --skill <id>
```

## How a skill reaches you (preview)

The specified workflow, from publisher workspace to your agent:

1. The publisher scaffolds a workspace and a skill.
2. They declare companion files and scripts with protection tiers.
3. They validate and build a deterministic release.
4. They issue your license key.
5. You install with `npx skills add` and the agent uses `list`, `search`,
   `read`, and `run` through the skill runtime.

Each step is documented in its guide. The command details live in the
[CLI reference](/docs/reference/cli).
